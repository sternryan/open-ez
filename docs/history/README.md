# History

Planning and review documents from earlier phases of open-ez, kept for the record. None of them
describes the current project. The current direction is the roadmap,
[`docs/superpowers/specs/2026-09-29-roadmap-same-airplane-new-process-design.md`](../superpowers/specs/2026-09-29-roadmap-same-airplane-new-process-design.md),
and the current state of the numbers is [`docs/block1-report.md`](../block1-report.md).

| file | what it was | dated | superseded by |
|---|---|---|---|
| `idea.md` | genesis research essay on a plans-as-code Long-EZ | Dec 2025 | the roadmap |
| `vision.md` | early pitch and vision statement | Dec 2025 | the roadmap |
| `implementation_plan.md` | original five-phase build plan, marked complete | Dec 2025 to Jan 2026 (committed Feb 2026) | the roadmap's blocks |
| `sprint_backlog.md` | sprint tracking for that plan, marked complete | Dec 2025 to Jan 2026 (committed Feb 2026) | `TODOS.md` and the roadmap |
| `swarm_strategy.md` | multi-persona agent strategy, archived | Dec 2025 to Jan 2026 (committed Feb 2026) | `AGENTS.md` |
| `swarm_personas.md` | the persona definitions moved out of `AGENTS.md` | Dec 2025 to Jan 2026 | `AGENTS.md` |
| `REVIEW_PROMPT.md` | review prompt for the Feb 2026 physics and manufacturing branch | Feb 2026 | the Block 1 audit (`docs/block1-report.md`) |
| `architecture_guide.md` | architecture due-diligence notes (was `codex_internal/notes/`) | Feb 2026 | `AGENTS.md` and the Block 1 audit |
| `WRAPUP_SIGNOFF.md` | parking note when the project was paused | 2026-05-23 | the roadmap (approved 2026-09-29) |

Numbers in these files are historical. Several were later found to be unsourced or wrong (for
example the RAF CP-29/CP-31 citations and the `fs_wing_le` calibration); see
[`docs/geometry-correction-ledger.md`](../geometry-correction-ledger.md).
